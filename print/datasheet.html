Gorad Factory Platform

Technical datasheet

Deployment, integration, inspection and security facts for engineers and plant IT.

Deployment
ServerUbuntu appliance, virtual machine or customer RHEL server
Station (Gorad Vision)Industrial PC on Ubuntu; NVIDIA GPU for stations that run heavier AI tools
User interfaceOne web application in any modern browser: LIVE screens for operators, SETUP for engineers
TopologiesStandalone on the machine network, or a connected site server
InternetNot required. No outbound connection, no telemetry by default
Network exposureHTTPS (443) only; TLS between browser, station and server; customer certificates supported
Data storesPostgreSQL for platform and app data; SQLite (WAL) journals on the station
Updates and releaseSigned update and program bundles, over the network or by USB, from the web interface
LicensingOffline activation; per-app entitlements. Licence state never affects inspection or the PLC output
Integration
PLC protocolsModbus TCP, Siemens S7, OPC UA (client)
Vision handshake signalsReady, Trigger, ResultOK / ResultNG (written after the journal and read back), Heartbeat (toggles every 0.5 s while healthy), LineUnsafe, PartToken, ProgramSelect, Ack; InPosition / CaptureDone per position for robot cells
CamerasGenICam / GigE Vision industrial cameras; USB cameras
Machine data (Gorad Connect)Tags mapped to standard events: machine.state, production.count, measurement, alarm. Store-and-forward through network drops. Read-only by default
Events between appsMQTT, or HTTP ingest when no broker is used
Apps (early access)
QualitySPC · NCR / CAPA · Calibration & MSA
ProductionLine Performance (OEE, Andon, downtime) · Maintenance · Tool & Fixture Life
Compliance & logisticsTraceability · Label & Dispatch · Skills & Training
ReportsPDF and Excel across the apps

Inspection (Gorad Vision)
Verdict ruleOK only if every expected view reports OK; error, timeout, missing, empty or unknown results are NG
Classical toolsPresence and count, measurement, colour, barcodes and data matrix codes, polarity and position
AI toolsAnomaly detection, object detection, OCR, classification, segmentation
Model families (licence-clean)PatchCore (anomaly), YOLOX (detection), RapidOCR / PaddleOCR (OCR), torchvision (classification), U-Net (segmentation)
Station typesStatic; stop-and-go with variants and barcode-driven program selection; multi-position robot cells
ProgramsSigned and verified before activation; golden-sample check; versioned with rollback
Security
PostureDesigned with IEC 62443 principles in mind. No certification or compliance is claimed; no third-party penetration test yet
AuthenticationLocal users, Argon2 password hashing, sign-in throttling; personal 6-digit PIN for operators on shared kiosks
AuthorizationRoles checked on the server for every request; re-authentication for production-changing actions
RolesOperator, supervisor, engineer, quality, maintenance, admin, viewer
SigningEd25519; separate keys for programs, updates and licences; private keys kept offline; stations hold public keys
AuditAppend-only audit log of configuration changes
Supply chainSBOM (CycloneDX) per release; dependency and secrets scans in CI; licence register; no AGPL, SSPL or GPL code shipped; no non-commercial model weights
Customer dataImages and results stay in the plant; no transfer to Gorad without explicit consent; exports audited; remote access off by default
Not available today
  • EtherNet/IP; Gorad Connect acting as an OPC UA server
  • Native Windows server install (the web interface works on Windows PCs)
  • Cloud hosting and multi-site fleet management
  • Full solder-joint AOI, 3D inspection and very high-speed line-scan web inspection
  • MES, ERP or WMS replacement

Status

The Gorad Factory Platform is in early access. Every app is built and tested in software; the pilot programme proves it on real stations before general release. Details in this datasheet can change; ask us for the current version.
